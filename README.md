# 📍 Morada AO

> Morada digital para Angola usando Plus Codes

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Made in Angola](https://img.shields.io/badge/Made%20in-Angola-red.svg)](https://angola.ao)

## 🎯 O Problema

Em Angola, milhões de pessoas vivem em zonas sem nomes 
de ruas formais. Isto dificulta entregas, emergências 
e serviços básicos.

## ✅ A Solução

Morada AO gera moradas digitais usando Plus Codes 
(Open Location Code do Google). Funciona em qualquer 
lugar, mesmo sem internet.

## 🚀 Features

- ✓ Gera Plus Codes a partir de GPS
- ✓ Funciona offline
- ✓ Partilha via WhatsApp/SMS
- ✓ 100% grátis
- ✓ Sem tracking ou dados guardados

## 🛠️ Tech Stack

- **Expo** (SDK 54, New Architecture, React Compiler)

- **React Navigation** (stack)
- **react-native-maps** + OpenStreetMap tiles
- **Plus Codes** (open-location-code)
- **Firebase** (Crashlytics, Analytics, Remote Config, FCM)
- **PostHog** (product analytics + session replay)
- **EAS Build + Submit** (Android + iOS)
