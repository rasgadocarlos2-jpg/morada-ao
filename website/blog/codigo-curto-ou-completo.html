Código curto ou código completo: qual partilhar

O curto é para dizer em voz alta. O completo é para partilhar.

EQUIPA MORADA AO · 21 DE NOVEMBRO DE 2026
RESPOSTA CURTA

Para partilhar por mensagem, escrever num formulário ou imprimir, usa sempre o código completo, como 6F3M576Q+2Q3. O código curto, como +2Q3 Cazenga, é mais fácil de dizer, mas repete-se a cada cerca de 275 metros e só funciona com o nome da zona certa.

Qual é a diferença

Código completo6F3M576Q+2Q3
Único no mundo. Funciona sozinho no Google Maps.
Código curto+2Q3 Cazenga
Só os últimos caracteres e o nome da zona. Precisa da referência para saber de que quarteirão se trata.

Porque o curto se repete

Os primeiros oito caracteres do código completo indicam um quarteirão com cerca de 275 metros de lado. O código curto deixa essa parte de fora e mantém só o que vem depois do +. Por isso, o mesmo +2Q3 existe em todos os quarteirões: no seguinte, no outro a seguir, e assim por diante.

O nome da zona (Cazenga) ajuda o Google Maps a adivinhar qual é. Mas se o município for grande ou o nome for ambíguo, o ponto pode aparecer no quarteirão errado.

Quando usar cada um

  • Completo: mensagens, formulários, cartões de visita, encomendas, tudo o que fica escrito.
  • Curto: para dizer ao telefone a alguém que já está na zona, ou para te lembrares da tua morada.

A Morada AO mostra o curto em grande porque é mais fácil de ler, mas o botão Partilhar morada envia sempre o código completo.

Perguntas frequentes

Posso converter um código curto em completo?

Sim, se souberes a zona. Escreve o código curto e o nome do sítio no Google Maps, confirma no mapa e copia o código completo que aparece nos detalhes.

O código completo é sempre o mesmo para a minha casa?

Sim. O código depende só da posição, por isso não muda.

Porque não mostram só o código completo?

Porque o código curto com o bairro é mais fácil de ler e de lembrar. Por isso a app mostra os dois e partilha o completo.
