O que é um Plus Code e como abri-lo no Google Maps

Um código que funciona como morada em qualquer sítio, mesmo sem nome de rua.

EQUIPA MORADA AO · 21 DE NOVEMBRO DE 2026
RESPOSTA CURTA

Um Plus Code é um código aberto, criado pela Google, que identifica um ponto do mundo a partir da latitude e da longitude. Com 11 caracteres, como 6F3M576Q+2Q3, corresponde a uma área de cerca de 3 por 3 metros. Para o abrir, cola-o na pesquisa do Google Maps.

Como se lê um Plus Code

O código divide o mundo numa grelha cada vez mais fina. Cada par de caracteres aproxima mais o ponto:

6FUma grande região do mundo
6F3MUma zona com cerca de 100 km de lado
6F3M57Uma zona com cerca de 5 km de lado
6F3M576Q+Um quarteirão com cerca de 275 m de lado
6F3M576Q+2QUm quadrado com cerca de 14 m de lado
6F3M576Q+2Q3Uma área com cerca de 3 por 3 metros

O sinal + aparece sempre depois do oitavo carácter. As letras usadas evitam vogais e caracteres que se confundem, como o O e o 0.

Como abrir um Plus Code no Google Maps

  1. Abre o Google Maps no telemóvel ou no computador.
  2. Cola o código completo na pesquisa, por exemplo 6F3M576Q+2Q3.
  3. O mapa mostra o ponto. A partir daí podes pedir o caminho como para qualquer outro sítio.

Como descobrir o Plus Code de um sítio

  • Com a Morada AO: abre a app no sítio e o código aparece logo, com o nome do bairro.
  • Com o Google Maps: carrega sem largar num ponto do mapa. Nos detalhes do ponto aparece o Plus Code.

Um Plus Code é uma morada oficial?

Não. É uma forma de indicar o local exato, aberta e gratuita, mas não substitui a morada oficial nem prova propriedade ou residência. Serve para que quem recebe o código chegue ao sítio certo.

Perguntas frequentes

Os Plus Codes são pagos?

Não. O sistema é aberto e qualquer pessoa ou empresa o pode usar sem pagar.

Funcionam fora de Angola?

Sim. Os Plus Codes funcionam em qualquer ponto do mundo.

Preciso de internet para ter o código?

Não. O código é calculado a partir das coordenadas do GPS, por isso a Morada AO consegue mostrá-lo sem rede. Para abrir o mapa é que precisas de internet.

Um Plus Code pode mudar?

Não. O código depende só da posição no mapa, por isso um sítio tem sempre o mesmo código.
